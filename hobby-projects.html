Project 01 · How it works

Closet Compass — from wardrobe to outfit suggestions

Closet Compass brings together clothing photos and categories, user preferences, weather context and occasion information. It uses AI-assisted recommendations to suggest combinations of available clothing while keeping the interface simple enough for everyday use.

What the application demonstrates

  • Wardrobe organisation, favourites and outfit planning
  • Recommendations informed by weather and occasions
  • AI integration through a Cloudflare Worker backend
  • Fallback recommendations when the AI service is unavailable

How it was evaluated

The latest locally tested version reportedly passed 70 of 70 automated tests, alongside browser-based checks of wardrobe management, image handling, preferences, recommendations, backups, error handling and responsive layouts. These are functional tests, not a formal measure of fashion recommendation quality.

The public app address is supplied by the project owner. The live deployment has not been independently tested in this preview.
Project 02 · Exploration

GlucoDiary AI — structured information, clearer insights

GlucoDiary AI explores how a personal data diary could use AI to help organise and interpret information. It provides a project space for examining understandable interfaces, reliable data handling and trustworthy summaries.

Project focus

  • Organising personal measurements and diary information
  • Exploring understandable presentation of trends and summaries
  • Investigating the boundaries of AI assistance for personal information

Evaluation status

The current repository's features, testing results, and model configuration have not yet been independently verified. Data-entry accuracy, persistence, error handling and summary consistency are evaluation criteria to check before publishing technical claims.

No verified live-demo link or performance metric is available yet. This project should be presented as experimental until its documentation is reviewed.
